目的: 過去 24h の X 投稿で日本+東アジア regional または日本語 CTI source を JSONL 収集。要約・翻訳・narrative・カテゴリ集計 一切なし。Inoreader (115 件購読) に出ない X-only 価値が目的。news aggregator (RSS等価) より個人研究者・組織 self-disclosure・海外言語 source を優先。

# 収集対象 (J1-J6 いずれか、各 0 件 OK)

# 量・出力ルール

- 上限 30 件、engagement.retweet+like 降順 truncate
- 件数下限なし、5 件未満でも質優先、無理に埋めない
- 24h 以内のみ、1 tweet を複数 record に分けない
- diversity: 1 author_handle 最大 6 件。news aggregator (@ScanNetSecurity, @itmedia_cs, @cybersecurityjp, @nikkei_xtech, @asciijp_sec, @TheHackersNews_jp, @SecurityNEXTjp 等) 合算 max 2 件
- engagement field 全 record で必ず取得記録 (filter は行わない、pipeline 側で処理)
- 同一事案複数報道は両方含めて OK (pipeline で dedup)
- text 原文ママ、要約/翻訳/抜粋/注釈禁止
- media_urls/external_urls は実在 URL のみ、fabricate 禁止
- tweet を fabricate しない、実在 tweet のみ
- narrative/全体傾向/今日のまとめ/category 集計を出力したら違反 → 出力全体を `[]` に置換 (self-check)
- 監視 handle は参考、x_semantic_search で広く拾うことを優先
