## 2. 母集団 (記事の定義)

単位は **記事** (事象の根ではない)。理由: 統合 (`merged_into`) は 60 日まで遡って根を付け替えるため、
事象の根で数えると過去の月の件数が実行のたびに変わり、§8 の「凍結して足す」が成り立たない。
事象の根の単位は副次 (§7)。

- **記事の 1 行化**: `articles` を article_id ごとに 1 行へ畳む。時刻は
  `src/storage/event_time.py` の `DEDUP_ARTICLES` と同じ (`MIN(created_at)`・`MIN(published_at)`)、
  属性は `status = 'posted'` の行を優先し、その中で `id` が最大の行 (前身の `extract.py` の `latest` と同じ)。
  `src/storage/repo_synthesis.py` の `_EVENT_TS_EXPR` / `_DEDUP_ARTICLES` は同じ定数の別名 (import) である
- **事象時刻**: `EVENT_TS_EXPR` (公開時刻。ただし取込より後なら取込時刻。欠損は取込時刻) を Asia/Tokyo で日に切る。
  `article_entities.created_at` 等の書いた時刻は使わない (CLAUDE.md §7)
- **取込の締め**: 日 d の属する暦月を M とすると、`MIN(created_at) < (M の翌月 1 日 00:00 JST)` の記事だけを数える。
  実行の日がずれても同じ行が入る (§8)
- **入れる**: `status = 'posted'` (配信されない分析専用の行 `analysis_only` を含む。地政学を分析の材料として残す
  利用者の意図に沿い、配信の有無で数を変えない)
- **外す** (数を月ごとに報告する):
  - `status` が posted 以外 (重複・抽出失敗・要約失敗・未処理)
  - `duplicate_of` が空でない記事 (投稿直前の重複判定に当たり分析に残った行。根だけを数える)
  - **新しい取得先の記事** (主の解析のみ。§5)
- **地政学の記事**: `category ∈ {geopolitical, policy}` (`src/cti/category_scopes.py` の `COVERAGE_GEOPOLITICAL`)。
  当事国 = `article_entities` の `entity_type = 'involved_country'` の値の和集合 (大文字 ISO2)
- **サイバーの記事**: `category ∈ {breach, incident, apt, apt_leak, malware, phishing, ransomware, vulnerability}`
  (`CYBER_THREAT_SCOPE`)
- **集合は字面で固定する**: 上の 2 つのカテゴリの集合と、下の同盟国の集合は、この文書の字面が正。
  コードの定数が後で変わっても、この測定は字面の集合を使う (変わったことは報告する)
- **同盟国**: `config/cti/countries.yaml` の `alliance: ally` (`src/cti/alliance.allied_nations`) の現値
  = US, GB, AU, CA, NZ, KR, TW, PH。日本 = JP。JA = {JP} ∪ 同盟国
- **国家系アクターの国**: 記事の `subject_actor_ids` の各 id を `src/cti/threat_actor_doctrine.state_nation_map`
  (アクター辞書は `src/cti/actor_normalizer.load_actor_aliases`) で国へ写す。主題は信頼条件
  `src/cti/subject_gate.trusted_subject_clause` (`subject_actor_source = 'llm'` かつ
  `subject_actor_confidence = 'medium'` を外す) を満たす記事のものだけ
- **ハクティビスト**: 信頼条件を満たす主題に `family = 'hacktivist'` のアクターを含む、または
  `socio_political_intent = 'hacktivism'` かつ `intent_confidence` が `low` でも空でもない記事
- **動機 (H2)**: `socio_political_intent ∈ {espionage, disruption}` (語彙は `src/cti/diamond_model.py`) かつ
  `intent_confidence` が `low` でも空でもない
- 本文は読まない・書き出さない (id・日・分類・国・アクター id・取得先の鍵だけ)

## 3. 系列 (bins) と山

日 d (JST) ごとに次を数える (§2 の母集団):

| 記号 | 中身 |
|---|---|
| G(d) | 地政学の記事の数 |
| G_X(d) | 当事国に X を含む地政学の記事 (X ∈ {CN, RU, KP, IR}) |
| G_ADV∧JA(d) | 当事国に {CN, RU, KP, IR} のいずれかと JA のいずれかを共に含む地政学の記事 |
| G_RUUA(d) | 当事国に RU または UA を含む地政学の記事 |
| T(d) | サイバーの記事の数 |
| C1_X(d) | サイバーの記事のうち、国家系の主題の国に X を含む |
| C2(d) | サイバーの記事のうち、被害国 (`victim_country_iso`、大文字) ∈ JA かつ (H2 の動機 または 国家系の主題の国 ∈ {CN, RU, KP, IR}) |
| C3(d) | サイバーの記事のうち、ハクティビスト |

- **地政学の割合 (山の元)**: s(d) = G_•(d) / G(d)。**G(d) < 10 の日は欠測** (停止・収集の断絶の日に
  割合が 0/少数で跳ねるのを防ぐ。10-28 以前の地政学の記事は通常これを大きく超える)
- **サイバーの割合 (結果)**: r(d) = C_•(d) / T(d)。**T(d) < 20 の日は欠測**
  (収集量のずれを総数で割って消す — CLAUDE.md §7「収集量を重要性の代理にしない」)
- **山の日**: 系列ごとに、次をすべて満たす日 t を「山に入った日」(onset) とする
  1. s(t) ≥ その暦月の s の **90 パーセンタイル** (欠測でない日で計算。numpy の既定 = 線形補間)
  2. 分子 G_•(t) ≥ 2 (1 件だけの日を山にしない)
  3. 前日 t−1 は 1・2 を満たさない (続く山の 2 日目以降は数えない。前の窓の汚れを減らす)
- **月の区切り**: 閾値は暦月 (JST) ごとに、その月の凍結した系列 (§8) だけで計算する (先の月を見ない)。
  10-29〜10-31 は 11 月と合わせて 1 つの区間 (34 日) として閾値を計算する。
  欠測の日がその区間の半分を超える月は、その月に山を置かない (結果の側の r は使う)
- **H1 の束ね方**: (X, t) の組を単位にし、X ごとに自分の結果の系列 r = C1_X / T を当てる。
  H2・H3 は系列が 1 本ずつ (G_ADV∧JA → C2、G_RUUA → C3)

## 4. 統計量

山の組 (H1 は (X, t)、H2・H3 は t) ごとに、窓 w = [a, b] について

- post_t = r(t+a)〜r(t+b) の平均、pre_t = r(t−14)〜r(t−1) の平均 (**基準は両方の窓で共通の直前 14 日**)
- 欠測の日は平均から外す。post か pre の窓で使える日が半分未満の組は捨てる
- **前の窓が 2026-10-28 以前に掛かる組・後の窓が確認の範囲の終わりを越える組は捨てる**
- 超過 E = mean_t (post_t − pre_t)、相対効果 R = E / mean_t (pre_t)

**帰無の分布 (置換)**: 地政学の側の山の印の系列を、確認の範囲の日数 N の円環で s 日ずらす。
s は [30, N−30] の**全ての整数を列挙** (乱数を使わない)。H1 は 4 国に同じ s を当てる。
片側 p = (1 + #{s : E_s ≥ E_obs}) / (1 + S)、S = N − 59。

- p の最小値は 1/(S+1)。ずらし幅 30 日以上は、遅れの窓 (最大 14 日) と前の窓 (14 日) が
  元の位置と重ならないための下限 (前身と同じ)
- **効果の区間**: 山の組を復元抽出する bootstrap 2,000 回 (`numpy.random.default_rng(20261201)`)、R の 95% 百分位区間

**標本の下限** (満たさない検定は「標本不足」とし、その回の族から外す。外した事実を報告する):
使える山の組 ≥ 20、かつ確認の範囲の結果の記事 (C の合計) ≥ 60。

## 6. 合否の線 (累積の判定)

**判定の回**: 確認の範囲の終わりを **2027-06-30** (N = 245 日、S = 186、p の最小 = 1/187 ≈ 0.0053) とし、
**2027-07-01 の回だけが「採用」を判定できる**。それより前の毎月の回は累積の記録と、下の「早期の打ち切り」だけ。
(採用の判定を 1 回に限るので、回を重ねることによる α の膨張は起きない。打ち切りは帰無を棄却しない方向なので
α を消費しない)

- 終わりの根拠: 前身の報告の見込み (同じ設計で +50% の効果に届くのは 6〜9 か月後) と、
  Holm の最も厳しい線 0.05/6 ≈ 0.0083 を p の最小値が下回る N (≥ 180 日) の両方を満たす最短の月末

**採用** (2027-07-01 の回で、仮説 h・窓 w の組ごと。1 組でも満たせば「その組を採用」):

1. 主の族 6 検定の Holm 補正の後の p < 0.05
2. 相対効果 R ≥ +20%、かつ bootstrap の 95% 区間の下限 > 0
3. 頑健性の確認と全取得先の確認 (§5) の両方で、同じ組の R ≥ +10%

**示唆のみ**: 1 を満たし 2 か 3 を欠く、または Holm 前の p < 0.05 かつ R ≥ +20% で Holm 後に落ちる。
採用しない (下の打ち切りと同じ扱い)。記録には残す

**打ち切り (放棄)**:
- 2027-07-01 の回で採用の組が無い
- **早期の打ち切り** (拘束しない): 2027-04-01 の回 (N = 154) 以降のどの回でも、主の族の 6 検定すべてで
  R の bootstrap 95% 区間の上限 < +20% (標本不足の検定は「上限 < +20%」とみなす) なら、その回で打ち切る
- 2027-07-01 の回で、主の族の 6 検定がすべて標本不足 → 「判定不能」として打ち切る (延長しない)

**継続**: 上のいずれでもない回 (2027-07-01 より前)。次の月を足す

**採用・放棄の意味**:
- 採用 = 「地政学の割合の山の後 w の窓で、h のサイバーの割合が増える」が確かめられた、という記録。
  **配信・重要度・台帳の確度への重みには直結しない** — 重みに使うなら、別の項目と事前登録と利用者の判断が要る
  (CLAUDE.md §7、収集量を重要性の代理にしない)。文脈の表示 (SIR・Spotlight で「山の後 w 日」を並べる等) の
  設計に進んでよい
- 放棄 = 毎月の回を止める。地政学は文脈として並べることを続ける (この測定の結果で変えない)。
  再開するなら、新しい事前登録と、それまでに見ていない範囲から

- **回**: 毎月 1 日 (台帳の GEO-LEADLAG-MONTHLY、最初の確認の回 2026-12-01 = 10-29〜11-30)。
  ホストの停止等で遅れても、§2 の取込の締めで同じ行が入る
- **dry-run**: 2026-12-01 より前の回 (GEO-LEADLAG-DRYRUN 11-06 = 10-29〜11-05) は道具の通しで、
  出力に「dry-run」と書く。報告してよいのは行数・欠測の日・除外の数・道具が回ったことだけ。
  **E・R・p・区間は出力しない** (計算しても書き出さず、判定・累積に入れない)。dry-run は凍結しない
- **凍結**: 各回は、締まった暦月 M (最初の回は 10-29〜11-30) の日ごとの系列 (§3 の表の全列 +
  除外の数 + 欠測の印) を `data/eval/geo_leadlag_monthly/<YYYY-MM>/series.json` に書き、sha256 を
  manifest に残す。**過去の月の系列は計算し直さない** (後でバックフィル・再分類・辞書の更新が DB を
  変えても、凍結した系列を使う)。山の閾値も凍結した系列から計算する
- **累積**: 各回は凍結した全ての月の系列をつなげ、§4 の統計量を確認の範囲の全体で計算し直す
  (山の組・ずらしの集合は N が伸びるたびに変わる。これは事前に定めた手順の一部)
- **凍結した系列の誤りの直し**: 誤りが結果を見ない確認 (DB の月の総数との突き合わせ、行数・欠測の検査) で
  見つかったときだけ、2027-07-01 の回より前に作り直してよい。§10 に日付・理由・作り直した月を書く。
  結果 (E・p) を見て気付いた誤りでの作り直しは、その後の結果を探索とする
- **manifest** (README の項目に加えて): 凍結した月ごとの sha256、アクター辞書
  (`config/cti/actor_aliases.yaml` 等、`load_actor_aliases` の読む先) と `config/cti/countries.yaml` の sha256、
  新しい取得先として外した鍵の一覧と件数、体制の区切りの日付、その回が dry-run / 累積 / 判定のどれか
- **報告**: 回ごとに主の 6 検定の E・R・区間・p (Holm 前後)・標本不足の印・使えた山の組の数、
  判定 (継続 / 打ち切り / 採用 / 示唆のみ)

## 9. 無効 (判定しない) とその扱い

- **この文書のコミットより前に、確認の範囲 (10-29 以降) の E・R・p を計算した記録が見つかった** → 無効。
  新しい確認の範囲で事前登録からやり直す
- **確認の範囲で 2 か月以上、主の母集団の地政学の記事が欠測でない日が月の半分未満** (収集の断絶) → その月は
  山を置かない (§3)。3 か月を超えたら判定不能 (打ち切り)
- **カテゴリの語彙が変わり、`geopolitical` / `policy` か §2 のサイバーの集合のいずれかの値が使われなくなった・
  別の値に分かれた** → その日以降は §2 の字面の集合では数えられないので、その日で確認の範囲を終える。
  そこまでの N で 2027-07-01 の判定を行い、N < 180 なら判定不能
- **新しい取得先の除外が効かない** (取得先の鍵が記事に付かなくなる等) → 全取得先の確認しか残らないので判定不能
- 主の解析で外した新しい取得先の記事が、全取得先の地政学の記事の 50% を超える月が 3 か月以上 → 主の母集団が
  収集の主流から外れたとして報告する (判定はするが「代表性の脅威」と明記する)
- この文書のコミットの後に §1〜§6 (仮説・母集団・系列と山・統計量・区切りの扱い・合否の線) を変えた → README の
  「線を変えてよいとき」に従い、変えた後の結果は探索

## 11. 既知の偏り (報告する)

- 時刻は報道の時刻で、発生の時刻ではない。サイバーは発生から報道まで日〜週の遅れがある
- 同じ報道の波が両方の系列を動かす共通の原因を分けられない (当日 0 を外すのは部分的な対策)
- 月末の数日は取込の締めで遅れて入る記事が欠けやすい (地政学・サイバーの両方に掛かり、割合では一部打ち消す)
- 当事国・被害国・主題・動機の付与は LLM と規則の出力で、モデルの切替 (fast ティア等) で分布が動く。
  モデルの切替は区切りの表に入れない (頻繁なため)。日付を報告に並べる
- 国家系の主題の記事は少ない (前身で週 0〜4 件)。H1 を束ねたのはこのため
- H2 の「敵性国と日本・同盟国が共に当事国」は向き (誰が誰に) を表さない
- 主の解析は新しい取得先を外すので、中露の国営媒体の視点は主に入らない (全取得先の確認で見る)
