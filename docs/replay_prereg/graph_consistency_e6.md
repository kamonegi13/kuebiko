## 1. 仮説

仮説ではなく水準の測定: 別々の部品 (主題・種別・被害国・焦点・統合・線) の食い違いを拾う規則 C1〜C6・C10 のうち、
どの規則の候補が「本当の誤り」を高い割合で含むか。誤りの割合が高い規則だけを、週次の整合の点検 (記録のみ、自動では直さない) に採る。
向き: 誤りの割合が高いほど規則は有用。指標: 層 (規則) ごとの 本当の誤り / 有効 n。

## 3. 期間と事象時刻の分割

## 4. 標本と重み

- 層ごとの n_k: **C1〜C5 各 8、C6 5、C10 5、対照 5 = 55 件** (Opus 55 回、再試行込みの上限 60)。
- 乱数種 **20261105**。各層の適格の鍵 (事象 id、組は昇順の `a|b`) を昇順に並べ、層名を混ぜた `random.Random` で shuffle して先頭から n_k 件
  (組の層は 1 つの事象を層の中で 1 回まで)。**N_k < n_k の層は全件**。manifest に「N_k < n_k の層」を出す。
- 判定の 3 値: **本当の誤り / 正常 / 判断できない** (Opus `claude-opus-5-5`・盲検、層の規則名と定義の文書を rubric で渡し、候補が誤りかを問う。1 件 1 回)。
  失敗は 2 回まで再試行し、なお失敗した件は「判断できない」と別に数える。
- 誤りの割合 e_k/n_k の **有効 n_k = 判定された件数のうち「判断できない」を除いた数**。「判断できない」の件数は層ごとに別に報告する。
- 区間: 層ごとに **Wilson 95% 区間** (有効 n で)。n が小さく区間は広い (4/8 で約 22〜78%) ので、線は「明らかに使える / 明らかに使えない」を分ける粗さと明記する。
- 重み (overall): 採用の層 k について **overall = Σ_k N_k·(e_k/n_k) / Σ_k N_k** (N_k = 窓内の層 k の除外後の母集団の件数、e_k/n_k = 有効 n 上の誤りの割合)。
  **対照の層は overall に入れない** (基準線のみ)。

## 5. 対の検定

n/a。両腕の比較は無く、規則ごとの割合 (Wilson 95% 区間) の水準測定。対照の層との差は参考で、検定しない。多重比較の補正もしない (層ごとの粗い線で読む)。

## 6. 合否の線 (結果を見る前に固定)

有効 n (「判断できない」を除いた数) で読む。

- 層ごと:
  - **採用**: 誤りの割合 **≥ 50%** (n=8 なら ≥4/8、n=5 なら ≥3/5)
  - **捨てる**: 誤りの割合 **≤ 12.5%** (n=8 なら ≤1/8、n=5 なら 0/5)
  - その間は **保留** (今は採らない。E6 の中では標本を足さない。再測定は GRAPH-G1-CONFIRM のデータで行う)
  - 有効 n < 5 の層 (全件を取っても、判断できないを除いても) は **保留** (採否不能)
  - N_k < n_k の層は上の割合で読む (全件の割合)。ただし有効 n < 5 なら保留
- **出す条件 (整合の点検を本番の段に出す)**: 採用の規則が **2 つ以上**、かつ採用の層の overall (§4 の式) **≥ 30%**。
- 対照の層は基準線として記録するだけ。「対照が 4/5 以上で誤りなら同じアクターの線の点検を規則に足す」は**不採用** (n=5 で規則化しない)。AT-10 の基準線の記録に留める。
- C10 の採否はここで決める (G1-DECIDE への入力)。

## 7. 汚染の鍵 (R18)

R18 の閉包は**適用しない**。理由は §2 のとおり (C1〜C6・C10 に学習・調整の集合が無く、守る対象が無い)。
代わりに E2 の組・事象と教師の保護の記事を外し、**外した数を層ごとに manifest と報告に出す**。
閉包の版の代わりに、除外に使ったファイル (`guard_n20_v2.json`・`guard_s26.json`・E2 の各ファイル) の sha256 を manifest に残す。
