## 1. 仮説

仮説ではなく水準の測定: 本番の関係の導き方 (`src/eventnews/relations.py`) が出す線のうち、型ごとに何割が
定義どおりの関係か。文章に渡せる型 (精度 ≥0.90 かつ Wilson 下限 ≥0.80) があるかを決める。
副次: 誤った線のうち主題アクターの誤りに由来する割合 (3a の効果の基準線)。

## 2. 母集団

- 事象: 本番と同じ `load_event_features(repo, days=60)` (統合されていない事象、last_reported_at が実行時から 60 日以内)。
  関係は本番と同じ `derive_with_model` (分類器 `config/models/relation_model.json`、閾値はモデルの値) と
  `index_relations` の上限 (同じアクター 5 件/事象・同じ出来事の関連 10 件/事象) を当てた後の線 = 画面・GraphRAG に出る線。
- 型:
  - **same_actor** (同じアクター): `rel_type = same_actor` の線
  - **incident** (同じ出来事の関連 = 分類器): `rel_type ∈ {incident, follow_up, side, contains}` の線 (分類器の確率 ≥ 閾値)
  - **lineage** (系統): (i) 焦点の照合の記録 `event_merge_vetoes.klass = 'lineage'` の組 (統合はされたが系統の候補として記録された組。
    事象は吸収前の item_id で示す) ∪ (ii) 規則だけの `derive_relations` が `side` と出す組
- 1 つの組は向きに依らない鍵 (事象 id の昇順) で数える。1 つの組が複数の型に入るときは 1 回だけ判定し、属する型すべての精度に数える。
- 除外 (順に当て、最初に当たった理由で数える):
  1. 過去の標本の組: `data/eval/graphrag_line_samples_v1.jsonl` / `_v2.jsonl`、`graphrag_line_audit_v1.jsonl` / `_v2.jsonl`、
     `graphrag_same_target_v2_all.json` / `_sample.json`、関係の分類器の学習・正解の組 `data/mlx/event_relations_goldset*.jsonl` (5 本)
  2. 上の組に出る事象を片方に含む組
  3. 上の事象と同じ根 (`merged_into` を辿った根、R18 の事象の根) の事象を含む組
  4. 教師の保護の記事 (`data/mlx/n20_teacher/guard_n20_v2.json` の ids ∪ `data/mlx/s26_teacher/guard_s26.json` の article_ids) を
     構成記事に持つ事象を含む組

## 3. 期間と事象時刻の分割

- 学習・調整は無い。判定する線は実行時点の本番の導き方 (60 日窓) の出力。関係の分類器の学習に使った組は §2 の除外 1〜3 で外す。
- 事象の期間は実行時から 60 日 (last_reported_at、本番の relations の窓と同じ。事象時刻の錨 `EVENT_TS_EXPR` ではなく事象の報道時刻で切るのは
  本番の線の定義に合わせるため)。

## 4. 標本と重み

- same_actor: 適格を鍵の昇順に並べ `random.Random(20261102)` で shuffle し、先頭から **60 組**。**1 つの事象は型の中で 1 回まで**
  (多産なアクターのハブに偏らない)。
- incident・lineage: 適格が 60 以下なので**全件** (事象の制約なし)。lineage が 60 を超えた場合は焦点の記録を全件取り、規則の side を同じ手順で足す。
- 重み: 型ごとに標本の単純な割合 (same_actor は無作為抽出、他は全数)。母集団への重み付けはしない (型の中では等確率)。
- Opus に見せる材料 (1 組 1 回): 各事象の見出し (最新の版、無ければ最初の構成記事の題)・初報 / 最終報の日付・構成記事の数・
  構成記事 (最大 6 本。多ければ時刻順の最初の 3 本と最後の 3 本) の題・媒体・公開日・要約 (先頭 600 字)・主題アクターの札
  (信頼できる経路 = feed / feed_match / title / llm-high の group の主題、構成記事の和集合)。
  **線の型・根拠・確率・cos は見せない** (盲検)。事象 1 / 事象 2 の並びは組ごとに `random.Random(20261102)` で決める。
- 判定役 (Opus `claude-opus-5-5`・effort high・temperature 0・`data/mlx/adjudication_cache.py` 経由、1 組 1 回) の指示 (逐語。
  `scripts/graphrag_eval/prompts.py` の `E2_RUBRIC`):

> あなたは CTI の上級分析官です。2 つの事象 (それぞれ、1 つの事案についての報道の束) の材料を読み、両者の関係を判定します。材料は事象の見出し・期間・構成記事の題・媒体・要約です。システムが機械的に付けた「主題アクターの札」も示します (札は誤っていることがあります)。
>
> ## relation (1 つ選ぶ。複数に当てはまるときは上にあるものを選ぶ)
> - 同じ事象: 同じ行為者 (または原因) による、同じ対象への、ひとまとまりの出来事。別媒体・別言語の報道や、同じ事案の第 n 報 (影響範囲・帰属・当局の警告・事後分析) を含む
> - 系統: 別の事象だが同じ出来事の流れにある。脆弱性の修正・告知 ⇔ その悪用・KEV への追加、事案から派生した別の主体の出来事 (行政指導・処分・声明)、まとめ記事・一括の勧告とその中の 1 件 (包含)
> - 同じアクターの別の活動: 同じ脅威アクター (同じ集団、その下位・別名) による、別の作戦・別の被害
> - 無関係: 上のどれでもない。共有するのが一般的な語・国・業種・頻出の道具・報じた媒体だけの場合を含む
>
> ## same_attacker
> 両事象の攻撃主体 (行為者) は同じ脅威アクター (同じ集団・その下位・別名) か。はい / いいえ / 不明。どちらかの行為者が材料から特定できないときは 不明。
>
> ## tag_1 / tag_2 (事象 1 / 事象 2 の主題アクターの札)
> - 正しい: 札のアクターが、その事象の行為者 (攻撃・作戦の主体) として報じられている
> - 誤り: 札のアクターはその事象の行為者ではない (言及・比較・別の事案・被害者側・報じた側など)
> - タグ無し: 札が空
> - 判断できない: 材料から決められない
> 札が複数あるときは、1 つでも誤りがあれば 誤り。
>
> reason は 150 字以内で、材料の事実だけを書く。

- 問い: 「事象 1 と事象 2 の関係を上の定義で判定してください。」 出力: relation / same_attacker / tag_1 / tag_2 / confidence / reason。
- 失敗 (例外・形の検証の失敗) は同じ入力で 2 回まで再試行 (Opus の回数に数える)。なお失敗した組は分母から外し、数を報告する。
- **Opus の回数**: 見積もり = 標本の組の数 (作成時の見込み 102 = 60 + 20 + 22、組の重なりがあれば減る)。上限は 1.3 倍 = **132**。
  キャッシュに当たる呼び出しは数えない。上限に達したら止めて報告する。

## 6. 合否の線 (結果を見る前に固定)

- 正誤の定義:
  - same_actor の線が正しい ⇔ same_attacker = はい (不明は誤りに数える。不明を除いた精度を参考に併記)
  - incident の線が正しい ⇔ relation ∈ {同じ事象, 系統}
  - lineage の線が正しい ⇔ relation = 系統 (厳密)。参考に {系統, 同じ事象} (緩い) を併記
- 用途の判定 (型ごと):
  - **書く材料に渡してよい**: 精度 ≥ **0.90** かつ Wilson 下限 ≥ **0.80**
  - **画面に出してよい**: 精度 ≥ **0.85** (書く材料の線に届かないとき)
  - それ未満は **どちらにも使わない** (今の画面の表示も見直しの候補として報告する)
  - n = 20 では 20/20 でも Wilson 下限 0.839、19/20 で 0.764 (書く材料の線は全問正解でしか通らない)。標本の小ささは判定を変えず報告に明記する。
- 副次 (合否に使わない): 誤った線のうち、tag_1 か tag_2 が「誤り」の割合 (主題の誤り由来、型ごと)。relation の分布、confidence が low の割合。
- §6.3 との対応: 書く材料に通る型が 1 つも無ければ、n21 の線の腕は E1 の結果に関わらず「線の型の精度が先」とする。
