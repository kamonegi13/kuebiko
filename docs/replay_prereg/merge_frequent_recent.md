# 事前登録: 頻出の名前だけを共有する近い時期の事象の統合 (EVENTNEWS_MERGE_FREQUENT_RECENT)

- 登録: 2026-11-21 (標本を抜いた後・Opus の正解付けの前にコミットする)
- 発端: 同じ出来事 (Cairn による医療画像 AI 基盤のゼロデイ悪用) が事象ニュースで 4 事象に割れていた (手動で統合済み)。

## 問題 (本質)

事象の統合・群化は、**頻出ガード (14 日で 12 記事超の名前は結合に使わない) をくぐった固有名の共有**だけで
候補を作る。頻出ガードは「道具・アクター・組織の名前だけで結ぶと別の事案が潰れる」を防ぐ正しい歯止めだが、
外した後に代わりの手がかりが無い。救済 (頻出の名前 + 本文 cos 0.80 以上、10-02) は大きな事案の後追い記事の
cos (0.5〜0.78) に届かない。結果として**何度も報じられる名前の、新しい大きな事案ほど割れる**
(CVE で 08 月に起きた逆転と同じ型)。11-21 の生きた事象で、頻出の名前だけを共有し cos < 0.80・ML 承認の
事象の組は 24h 以内 280 / 72h 以内 475 (Binance の窃取・Optimizely・ATF と Qilin など)。

## 変更 (旗)

`EVENTNEWS_MERGE_FREQUENT_RECENT=0|shadow|1` (`src/eventnews/merge.py:frequent_entity_pairs`)。
頻出の名前を共有する別事象の記事対を、cos ≥ 0.80 **または** (記事の時刻の差 ≤ G 時間) で候補にし、
判定は既存の ML に回す。ML の承認に追加の下限 P (確率) を掛ける (cos ≥ 0.80 の従来の組には掛けない)。
その後の関門 (焦点の照合・ハブ・閉包の照合し直しなど) は従来どおり。shadow はログのみ。

## 標本 (凍結)

`data/eval/cairn_split_1121/frequent_pairs.json` (11-21 12:3x JST、本番と同じ入力の読み取り) から、
cos < 0.80・ML 確率 ≥ 0.60・時刻差 ≤ 168h の記事対を事象の組ごとに 1 つ (確率が最大の対) にまとめ、
確率 3 帯 [0.60, 0.75) / [0.75, 0.85) / [0.85, 1] × 時刻差 3 帯 ≤24h / (24, 72] / (72, 168] の 9 層から
各 6 組 (乱数種 20261121)、計 54 組。`data/eval/cairn_split_1121/sample.jsonl`
(sha256 `4b684ae2c8415cd613ebefb11e2ce1db98bc80157473bce2b6acdb91807a073e`、道具 `data/eval/cairn_split_1121/tools/label_pairs.py`)。
層の母数 (確率帯 × 時刻差帯): 108 / 88 / 140 / 82 / 49 / 48 / 76 / 37 / 19。

## 正解

- Opus 5.5・effort high・1 回 1 組・盲検 (ML の確率・cos・事象の id は見せない)。
- 材料: 2 記事の題・媒体・公開時刻・本文全体と、`docs/event_identity_definition.md` §1 の定義 (逐語)。
- 出力: same / lineage (系統: 修正 ⇔ 悪用・派生) / contains (まとめ・包含) / different / boundary。
- 2 回独立、割れたら 3 回目で多数決、2 回で割れた組は境界。
- **統合として正しいのは same だけ** (lineage・contains・different は誤統合)。

## 線 (この登録で固定する)

候補の範囲 (P, G) を広い順に (0.75, 72) → (0.75, 24) → (0.85, 72) → (0.85, 24) と試し、範囲に入る標本の組
(境界を除く) で誤統合が 1 件以下かつ適合率 ≥ 0.95 を満たす**最初の**範囲を採る。
- 満たす範囲があれば、その (P, G) で旗を 1 にする (利用者の指示 11-21「本質を解決する」による)。
- どれも満たさなければ旗は shadow のまま、誤りの型を報告する。
- [0.60, 0.75) の層と 72〜168h の層は線の外 (参考の数字。どこまで広げられるかの見込み)。
