## 1. 仮説

D2 (下の規則で作る写像) は、P (影の対を連結した写像、本番の既定) と比べて
(i) 同一とする名前の組の適合率が十分に高く (ii) P より悪くなく (iii) 統合の焦点の関門の拒否を目立って増やさない。向き = 非劣性。

## 2. D2 の作り方 (固定) と根拠

T・材料・伏字のキーは前回と同じ (`org_alias_d.md` §2): **T = 2026-11-10T00:00:00+09:00**、材料 = `org_identity_pairs` の
`form = 'and_event12_org-4_v2'`・`logit >= 0`・`judged_at < T`、伏字のキーを含む組は外す。

D2 は材料の辺 E (伏字を除いた同一の組) から次の 2 段で作る:

1. **同じ記事に別々に並ぶ組を辺にしない**: 2 つの照合キーが、`created_at < T` の `article_entities` (`entity_type='victim_org'`)
   で**同じ article_id に別々の被害組織として**現れる組は E から外す。
   根拠: 判定役の問いは「事象が同じか」(余裕 12) と「組織が同じか」(-4、緩い) の AND で、同じ事案の別の被害者は
   事象の問いを強く通り、組織の問いの緩い線だけが残る (問いの形からの弱点。判定の rubric でも「同じ事案の別の被害者」は
   別の組織と定義)。1 つの記事が 2 つを別の被害組織として抽出していることは、その弱点の組の構造上の印。
2. **閉包は直接の辺で裏付けられる範囲だけ**: 1 で残った辺の連結成分ごとに、成分を「中のすべての組が E の辺である」
   (= 辺の上の完全部分グラフ) 群に分け、**覆う辺の数が最大**の分け方を選ぶ。各群の最小キーを代表キーにし、
   大きさ 2 以上の群のキーだけを写像に入れる (`build_alias_map` と同じく代表キー自身も入る)。
   - 決定論: 成分のキーを昇順に並べ、各キーを (作った順の) 既存の群のうち入れられるものへ順に試し、最後に新しい群を作る
     探索で、覆う辺の数が**厳密に**最大になった最初の分け方を採る
   - 成分のキーが 12 を超えるときは探索をやめ、辺を (key_a, key_b) の昇順に見て「両側の群のすべての組が辺なら合流」の
     貪欲で作る (T の材料では成分の最大は 6 なので使われない)
   根拠: 写像 (照合キー → 代表キー) は推移的な関係しか表せない。判定役が直接に同一とした組の外へ同一を広げない。
   T の材料の構造: 辺 130 (伏字を除く) のうち、D の連結成分 91 のうち完全部分グラフになっている成分は 75 (大きさ 2 が 74・3 が 1)。
   D の閉包の組 169 のうち辺でない組は 39 (うち 8 は判定役が**別**と判定済み = logit < 0 の行、31 は未判定)。
   閉包は判定役自身の判定と 8 組で矛盾する

**採らなかった案と理由**
- 辺の確率 (logit) の閾値を上げる: 材料の logit は 128/135 が上限の 3.0 に張り付き (残りは 0.6〜2.x の 7 件)、区別に使えない
- 成分の大きさの上限 (例 3 以下): 2 の規則で群は完全部分グラフになり、大きさの上限より直接の根拠に近い。
  上限だけでは大きさ 3 の鎖 (a–b–c で a–c が未判定) の閉包が残る
- 判定役の再判定・閾値の再調整: Ollama を使わない制約と 11-17 の期限、調整と測定の標本の分離のため今回はしない

**D2 の件数 (本書を書く前に計算した値。正誤は見ていない)**: 1 で外れる辺 10、2 の分け方で覆われない辺 21、
写像のキー 189、群は大きさ 2 が 90・3 が 3、閉包の組 C_D2 = 99、C_D2 ⊆ C_P。

- **pins** (ORG-D-SWITCH が D2 で出荷するときの値): `version` = `asof:2026-11-10T00:00:00+09:00;form:and_event12_org-4_v2;mode:d2`、
  `rows` = D2 のキーの数、`hash` = 前回と同じ式 (`mapping_sha256`)。`scripts/build_org_alias_dict.py --as-of T --mode d2` が同じ値を出す

## 5. 指標と合否の線 (結果を見る前に固定。前回と同じ線)

- **L1**: 層 A の適合率 (`same` ÷ (`same` + `different`)) の点推定 ≥ 0.95 **かつ** D2 の群 (代表キー) を単位とする
  クラスタ bootstrap (2,000 回、`random.Random(20261113)`、百分位法) の 95% 区間の下限 ≥ 0.90。Wilson を併記
  - ⚠ 母集団は「C_D2 から前回の標本と汚染を除いた組」。前回の標本は C_D の無作為標本なので、残りは C_D2 の
    (前回の抽出についての) 無作為な部分。n が小さく (36 組以下)、下限 0.90 は誤りがほぼ 0〜1 組でないと満たさない
- **L2**: 前回と同じ (層 B の b = `same`・c = `different`、McNemar 片側 b > c かつ p < 0.05 なら不合格、
  重み付きの正答率の差 D2 − P ≥ −0.02、`unclear` を除く)。母集団は C_P から前回の標本と汚染を除いた組
- **L3**: 前回と同じ veto の両向きの再現 (`org_alias_d.md` §6、窓 [T − 14 日, T)) を P(T) → D2(T) で。
  「通る → 拒否」 ≤ max(2, ⌈0.02 × 窓の統合の判断の件数⌉)。「拒否 → 通る」は報告のみ
- **総合**: L1 ∧ L2 ∧ L3 で合格 (ORG-D-SWITCH を D2 で進める)。1 つでも満たさなければ不合格 (切替しない)
- **判定不能**: 判定できた組 (`same` / `different`) が標本の 80% 未満、層 A で判定できた組が 25 未満、
  `unclear` の重み付きの割合が 0.20 超、Opus が上限で止まり未判定が標本の 10% 超、C_D2 ⊄ C_P、のどれか
