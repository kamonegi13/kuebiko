# 強い教師からの蒸留 — 何が転移し何が転移しないか (調査: 2026-09-05)

> ⚠ 出典は調査時に収集したもの。筆者が独立に再検証したものではない。

## ⭐ 形式は速く転移し、知識・能力は転移しにくい

- **形式・文体は少データで確実に転移** — LIMA の "Superficial Alignment Hypothesis":
  SFT が教えるのは主に応答の書式で、知識は事前学習由来
  ([arXiv:2305.11206](https://arxiv.org/abs/2305.11206))
- **知識・事実性は転移しにくい** — "The False Promise of Imitating Proprietary LLMs" は
  模倣モデルが「**文体は模倣するが事実性は模倣しない**」ことを示した
  ([arXiv:2305.15717](https://arxiv.org/abs/2305.15717))
- ⭐⭐ **「精度」と「能力」を分けるべき** — 推論パターンだけを蒸留した生徒は
  **精度 (1 発正答率) は上がるが能力 (pass@k) は上がらない**。k を増やすと base の曲線に収束する
  ([arXiv:2505.14216](https://arxiv.org/html/2505.14216))

## hard label のみで学習する限界

- 教師の内部状態に届かないため、クラス間の相対的類似度 ("dark knowledge") が失われる
  ([arXiv:2401.07013](https://arxiv.org/abs/2401.07013))
- ⭐ より本質的なのは **露出バイアス** — 固定された教師出力だけで SFT すると、
  学習時に見る系列と推論時に生徒が生成する系列の分布が乖離し、
  **生徒が自分のミスから回復する経路を一度も学習しない**
  ([GKD, arXiv:2306.13649](https://arxiv.org/abs/2306.13649))

## 生徒が教師を超える現象

- **weak-to-strong generalization**: 弱い教師は新規に教えるのではなく、
  強い事前学習モデルが既に持つ潜在能力を **elicit する**
  ([arXiv:2312.09390](https://arxiv.org/abs/2312.09390))
- 教師の確率分布に忠実に従わないほうが良い場合がある (逸脱が正則化的に働く)
  ([NeurIPS 2023](https://proceedings.neurips.cc/paper_files/paper/2023/file/12d286282e1be5431ea05262a21f415c-Paper-Conference.pdf))

⚠ **どのサブタスクで逆転が起きるかを予測する定量理論は文献に無い。**

## ⭐⭐ 蒸留で最初に壊れるのは長尾

- 推論パターンのみの蒸留は、**最も難しい bin で約 38.9 ポイントの低下**
  ([arXiv:2505.14216](https://arxiv.org/html/2505.14216))
- cross-entropy SFT は単一の支配的モードに収束し、**稀少な妥当応答を不均衡に抑圧する**
  ([arXiv:2604.16027](https://arxiv.org/pdf/2604.16027))

⚠ 量子化・枝刈りの文献は**逆方向**の結果 (tail のほうが保持されやすい) を報告しており
([arXiv:2608.19670](https://arxiv.org/abs/2608.19670))、**機序が違うので単純に外挿できない**。

## ⭐⭐ CoT 蒸留は「制約付きデコード下でも」実現可能だった

私は以前「推論を出す場所がスキーマに無いので CoT は入れられない」と述べたが、**不正確**。
確立された 2 つのパターンがある。

**1. 学習時のみ rationale を補助タスクにする** — Distilling Step-by-Step。
推論時には rationale を生成させず label のみ出力。770M の T5 が 540B PaLM の few-shot を
学習例 80% 未満で上回った ([arXiv:2305.02301](https://arxiv.org/abs/2305.02301))。
**スキーマに CoT 欄が無くても、学習信号としてだけ使える。**

**2. schema の先頭に一時フィールドを置き、下流で破棄する** — 自己回帰生成は schema の
プロパティ順に従うため成立する。実務で使われ、学術的にも
"Thinking Before Constraining" ([arXiv:2601.07525](https://arxiv.org/pdf/2601.07525)) /
"Think Inside the JSON" ([arXiv:2502.14905](https://arxiv.org/pdf/2502.14905)) が支持。
**素朴な制約付きデコードは推論品質を損なう**とも報告されている。

## 複数教師を混ぜること

⚠ 目的が競合すると単純平均は害になる。MOPD は
「recovery-preservation counteraction (教師勾配の衝突)」と
「weak-signal flattening (一様平均による弱信号の希釈)」を実測し、
**教師群が同一 SFT チェックポイント由来であることが安定性の条件**と明記
([arXiv:2606.30406](https://arxiv.org/pdf/2606.30406))。

→ 9月3日に「教師は混ぜない (混成だと生徒が平均を学ぶ)」と判断したのは文献と整合。

## 手元の実測との対応

| 実測 | 整合する文献 |
|---|---|
| 契約の学習が 150/700 = 21% で完了 | LIMA / Superficial Alignment。**複数文献で再現された頑健な知見** |
| ATT&CK 抽出が 700 反復でも教師の 39% | (a) 模倣データに薄いタスクはギャップが閉じない (b) 新規知識を伴わない蒸留は能力を上げない (c) 長尾が抑圧される — **3 つが同じ方向を指す** |
| IOC で教師超え (4.02→4.45) | weak-to-strong + ノイズ相殺で定性的に説明可。⚠ **予測理論は無い**。IOC が低曖昧度・高規則性、ATT&CK が高曖昧度・長尾という構造差が最も説得的だが**類推にとどまる** |
| triage の Sonnet 一致 55%→71% | 「精度は蒸留で伸びる」と整合。⚠ ただしこれは **accuracy の代理指標であって capability の代理ではない** |

⚠ **説明されない残差**: (1) 150 vs 700 という速度比を予測する数値モデルは無い
(2) 主要な実証はほぼ数学・コード推論領域で、**CTI 抽出への転移自体が未検証**
